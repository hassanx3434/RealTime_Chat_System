# 💎 نظام التواصل الشبكي المشفر عالي الاستقرار | لوزارة التطوير

نظام محادثة فوري ونقل ملفات آمن (Client-Server Architecture) مبني بالكامل بلغة **Python** وباستخدام هندسة البرمجة غير المتزامنة (**Asyncio**). تم تطوير هذا النظام ليلبي الشروط الصارمة الخاصة بالأداء، الحماية السيبرانية، واستقرار الجلسات عند ضغط المستخدمين.

---
## 🛠️ التقنيات والمكتبات المستخدمة (Tech Stack)

تم بناء النظام بحد أدنى من الاعتماد على المكتبات الخارجية لضمان الخفة والسرعة:
* **Asyncio (مكتبة قياسية):** لإدارة الاتصالات الشبكية المتزامنة والضخمة بكفاءة عالية وبدون استهلاك لموارد المعالج.
* **SQLite3 (مكتبة قياسية):** كقاعدة بيانات خلفية خفيفة وسريعة لتخزين الحسابات، الصلاحيات، وقوائم الحظر.
* **Json & Base64 (مكتبة قياسية):** لترميز وتغليف البيانات والملفات بشكل نصي آمن داخل الشبكة.
* **Custom XOR Cipher (خوارزمية مخصصة):** لتطبيق تشفير متناظر (Symmetric Encryption) على مستوى الحزمة (Payload Encryption).
* **Arabic-Reshaper & Python-Bidi:** مكاتب متخصصة في معالجة وحل مشكلة النصوص العربية في تيرمينال الويندوز لتظهر الحروف متصلة ومنسقة (RTL Support).

🚀 دليل تشغيل النظام خطوة بخطوة (How to Run)

📥 المتطلبات المسبقة:
افتح التيرمينال في جهازك وقم بتثبيت أدوات معالجة اللغة العربية عبر الأمر التالي:


python -m pip install arabic-reshaper python-bidi

1️⃣ الخطوة الأولى: تشغيل السيرفر الرئيسي (The Server)
افتح نافذة تيرمينال (Terminal) جديدة.

توجه إلى مجلد السيرفر واكتب الأمر التالي لتشغيله:


cd server
python server.py
ستلاحظ ظهور رسالة تفيد بأن السيرفر يستمع الآن على المنفذ 127.0.0.1:5555 وبدأ نظام الـ Logging تلقائياً.

2️⃣ الخطوة الثانية: تشغيل عملاء المحادثة (The Clients)
النظام يدعم تعدد المستخدمين بكفاءة (Multi-client). لتجربة محاكاة الضغط والتنقل:

افتح 3 أو 4 نوافذ تيرمينال منفصلة (Windows Terminal أو CMD).

في كل نافذة، توجه إلى مجلد الكلاينت وشغّل البرنامج عبر الأمر التالي:


cd client
python client.py
ستظهر لك في كل نافذة الواجهة البصرية الأنيقة لتسجيل الحساب أو الدخول.

🔑 الدليل الإداري: كيف تضيف "أدمن" (How to Grant Admin Role)

    افتح التيرمينال في مجلد السيرفر:

cd server
شغل السكريبت:

python make_admin.py
اكتب hassan أو أي اسم حساب مسجل عندك، واضغط Enter.

💡 دليل الأوامر ولوحة التحكم المتاحة
👤 أوامر المستخدمين العاديين (Users):
/rooms : يعرض لك الأقسام المتوفرة (عام، برمجة، ألعاب) ويخبرك بقسمك الحالي.

/join اسم_الغرفة : ينقلك فوراً إلى القسم المطلوب (مثال: /join برمجة).

/online : يظهر لك أسماء الأشخاص المتواجدين معك داخل نفس القسم حالياً.

/msg اسم_المستخدم النص : لإرسال رسالة خاصة سرية ومحمية لا يراها بقية أعضاء القسم.

/file مسار_الملف : لمشاركة ملف من جهازك (صورة أو نص) ليتم تشفيره وتحميله تلقائياً لدى بقية أعضاء الغرفة (مثال: /file test.txt).

exit : تسجيل الخروج وإغلاق الجلسة بأمان.

🛠️ أوامر الأدمن للتحكم بالطرد والحظر (Admin Only):
عند كتابة هذه الأوامر من حساب رتبته أدمن، يتم تنفيذ العقوبة شبكياً وفورياً:

/kick اسم_المستخدم : يقوم بفصل المقبس الشبكي للمستخدم فوراً وطرد جلسة العميل من السيرفر.

/ban اسم_المستخدم : يقوم بحظر اسم المستخدم وتعديل حالته في قاعدة البيانات لمنعه من تسجيل الدخول إلى النظام نهائياً حتى لو أعاد تشغيل البرنامج.
